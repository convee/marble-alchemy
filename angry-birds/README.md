# Angry Birds

Angry Birds is a self-contained, English-first browser game in the Chaoschemy catalog. It uses HTML5 Canvas and Matter.js for the slingshot, destructible structures, pigs, levels, and touch controls.

Open `/angry-birds/` to play. The game has no account wall and sends only anonymous gameplay events to the shared Chaoschemy analytics worker.

Matter.js is loaded from jsDelivr at runtime; the license notice is in `THIRD_PARTY_NOTICES.txt`.
