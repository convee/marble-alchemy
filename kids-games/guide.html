How the AI companion participates

The companion can give a hint, set a daily quest, or cheer after a difficult round. Each request uses a small allowlisted state such as level, moves, hearts, goals, or collected items. It never asks for a name, voice, photo, contact detail, or chat history.

If the cloud model is unavailable, the same actions use deterministic offline copy and the games stay playable.

What parents should know

  • No download or account is required.
  • Progress and the daily streak are stored in the current browser.
  • Support links are behind a parent check and open the separate support page.
  • The games are short browser experiments, not a replacement for school or supervised play.
