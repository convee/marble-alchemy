Why this is different

Aim and launch a marble, let real peg collisions build damage, then choose one of three upgrades after each victory. Five stages escalate the pressure; six upgrades shape each run. The AI Director changes one bounded rule each day so the same board asks a new question.

How the AI Director participates

The model writes a narrative prophecy, a validator constrains it to three auditable mechanics, and the browser executes the mechanic locally. Your result then receives a model-authored strategy plus measured run stats. No browser key or opaque per-frame model call is required.
