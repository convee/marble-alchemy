弹珠炼金工坊 · 双版本对比

同一份中文需求，交给两个模型各自从零实现的浏览器弹珠 Roguelite。两版都用 TypeScript + Phaser 3.90 + Matter 物理 + Vite， 都不接后端与在线 AI，美术与音效全部程序生成。代码、测试与证据分别放在同一个仓库的两个目录里，可以直接对照阅读。

Codex · GPT-6

目录 gpt6/

  • 规则测试 10 项、浏览器测试 16 项（该版自测口径）
  • 完整无剪辑通关录屏，含 SHA-256 校验清单
  • Prettier 格式检查与 npm audit 进 CI

Claude Code · fable 5.1

  • 12 局机器人自动对局：胜率 42%，0 局卡死
  • 逐帧合成录屏，画面不受运行环境帧率影响

玩法一致的部分

两版都遵循同一份需求：瞄准发射弹珠，弹珠撞钉子累计伤害，所有弹珠落底后统一结算；敌人存活则反击，玩家初始 5 点生命； 五关递增，每次击败敌人后从 3 张里选 1 个升级；升级池固定为强化、火焰、闪电、分裂、暴击、治疗六种， 其中强化与火焰可重复获得。具体数值、弹盘布局、视觉与音效由各自设计。
